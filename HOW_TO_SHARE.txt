═══════════════════════════════════════════════════════════════
  OPTION 1: SHARE THE ZIP FILE (RECOMMENDED)
═══════════════════════════════════════════════════════════════

1. Find the file: codelearn\codelearn-shareable.zip

2. Upload to:
   • Google Drive → Share link
   • OneDrive → Share link  
   • Dropbox → Share link
   • Email (if small enough)
   • WeTransfer (for large files)

3. Send the link to your partners

═══════════════════════════════════════════════════════════════
  OPTION 2: MANUAL ZIP CREATION
═══════════════════════════════════════════════════════════════

If you prefer to create your own ZIP:

1. Right-click the "codelearn" folder
2. Select "Send to" → "Compressed (zipped) folder"
3. Before sharing, delete these from the ZIP:
   - node_modules folder
   - .next folder
   - data\db.json (if exists)

═══════════════════════════════════════════════════════════════
  WHAT YOUR PARTNERS NEED TO DO
═══════════════════════════════════════════════════════════════

After receiving the ZIP file:

1. Extract the ZIP to a folder
2. Open terminal/command prompt in that folder
3. Run: npm install
4. Run: npm run dev
5. Open: http://localhost:3000

   - .next (build files)
