# 🚀 CodeLearn - Hackathon Project Summary

## What We Built

A **full-stack platform** that merges **Udemy** (course learning) with **LeetCode** (coding practice) into one unified experience.

## ⚡ Quick Start (30 seconds)

```bash
cd codelearn
npm install
npm run dev
```

Open http://localhost:3000

## 🏗️ Architecture

- **Frontend**: Next.js 14 (App Router) + React + TypeScript
- **Styling**: Tailwind CSS (fully responsive)
- **Code Editor**: Monaco Editor (VS Code editor)
- **Backend**: Next.js API Routes
- **Database**: JSON file (simple, fast for demo)
- **Auth**: JWT + bcrypt

## 📊 Demo Flow

1. **Homepage** → Shows featured courses & problems
2. **Register** → Create account
3. **Browse Courses** → Enroll in a course
4. **Watch Course** → Video player interface
5. **Solve Problems** → Code editor with submissions
6. **Dashboard** → View progress & stats
